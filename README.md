# gh-scope

Терминальный обозреватель GitHub: профили, поиск, организации, дуэли, коллекции, радар релизов и тренды. Чистая статическая SPA (React + Vite + Tailwind v4) — без бэкенда и секретов: все запросы уходят из браузера напрямую в `api.github.com`.

## Возможности

- **Обзор профиля** — витрина репозиториев, фильтры, сортировки, языковой срез, экспорт JSON
- **Поиск** — комбинации фильтров (язык, звёзды, лицензия, тема, владелец, даты) и живой итоговый запрос
- **Организации** — `/orgs/{org}/repos`, флот с сортировкой и языками
- **Дуэль профилей** — сводный счёт по шести метрикам
- **Дуэль репозиториев** — две карточки бок о бок
- **Коллекции** — свои awesome-листы, хранятся локально
- **Радар релизов / Наблюдение** — следите за репо и видьте изменения
- **Тренды** — быстрорастущие репо по скорости набора звёзд
- **README** — рендер markdown, машинный перевод → RU, ссылки на DeepWiki и GitMCP
- Тёмная/светлая тема, интерфейс EN/RU, закладки, горячие клавиши

## Локальный запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # прод-сборка в dist/
npm run typecheck
```

## Хостинг

Это статика: публикуется каталог `dist/`. Подходит любой статический хост.

- **GitHub Pages** — готовый workflow в `.github/workflows/pages.yml` собирает и публикует
  `dist/` на каждый push в `main`. В настройках репозитория нужно один раз выбрать
  **Settings → Pages → Source: GitHub Actions**.
- **Vercel / Netlify / Cloudflare Pages** — build: `npm run build`, output: `dist`

В `vite.config.js` стоит `base: "./"`, поэтому сборка работает и под подкаталогом
(`user.github.io/gh-scope/`), куда Pages её и кладёт. Навигация хеш-роутинговая, так что
прямые ссылки на разделы не дают 404 на статике.

> GitHub Pages в **приватном** репозитории доступен только на платных планах
> (Pro / Team / Enterprise). На Free приватный репозиторий Pages не получит —
> в этом случае либо Vercel/Netlify/Cloudflare, либо репозиторий публикуется.

## Настройки (кнопка с ключом в шапке)

Оба поля хранятся **только в `localStorage` этого браузера** и никуда не отправляются, кроме
сервисов, которые вы сами назвали. Это не компромисс, а следствие статического хостинга: сервера,
который мог бы держать ваш ключ, здесь нет, а всё, что вшито в бандл, публично по определению.

**Токен GitHub.** Без токена API даёт 60 запросов/час на IP и скрывает приватные репозитории.
Классического токена **без единого scope** достаточно, чтобы поднять лимит до 5000/час; scope
`repo` нужен, только если хотите видеть приватные репо.

**Эндпоинт перевода.** Необязательно. Встроенный транспорт зовёт публичный эндпоинт Google
(`translate_a/single?client=gtx`) — это **не документированное API**, а точка, которую дёргает
виджет Google Translate, и Google может её закрыть в любой момент. Если указать свой URL,
совместимый с LibreTranslate (`POST /translate` → `translatedText`), он пробуется **первым**,
публичный остаётся запасным.

## Лимиты

Без токена публичный API даёт 60 запросов/час на IP. Счётчик виден в шапке. Поиск: ~10 запросов/мин без токена.
